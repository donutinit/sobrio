sobrio бере одну невелику частину від [Stylus](https://github.com/openstyles/stylus), [Dark Reader](https://github.com/darkreader/darkreader), [Search Bookmarks, History and Tabs](https://github.com/Fannon/search-bookmarks-history-and-tabs), [Tabliss](https://github.com/joelshepherd/tabliss) та [Global Speed](https://github.com/polywock/globalSpeed), і нічого більше. Одне розширення для Firefox, LibreWolf і Chrome, два кольори, жодних заокруглених кутів, і ніщо не виходить з вашого браузера.

![Switcher відкритий над Вікіпедією, яку sobrio зробив чорною: введене «ru» показує закладки Rust із виділеними жирним збігами літер.](docs/screens/switcher.png)

## Що вона робить

### Одна таблиця стилів скрізь

Без заокруглених кутів, тіней, тіней тексту й розмиття. Анімації та переходи вирізано повністю, крім відеоплеєра YouTube. Без смуг прокручування, без плавного прокручування, фони прокручуються разом зі сторінкою. Посилання підкреслені, будь-який текст можна виділити, великі літери CSS не нав'язує.

Кожна деталь є перемикачем у налаштуваннях (тонкі смуги прокручування замість їх відсутності теж), і ще два вимкнені за замовчуванням: зображення й відео у відтінках сірого та видима рамка фокусу. Нижче є поле для вашого власного CSS (до 50 000 символів), в окремому аркуші після стилів sobrio на кожному сайті, тож `@import` на його початку працює.

### Чорне, але розумно

![Стаття Вікіпедії про типографіку: ліва половина так, як її малює сайт, біла, і права половина з sobrio, чорна.](docs/screens/wikipedia.png)

Динамічний рушій Dark Reader робить кожен сайт чорним (`#000`), колір за кольором. Сайти з власною темною темою її зберігають. Яскравість, контраст, сепію, відтінки сірого та кольори налаштовують у налаштуваннях; розкладів немає.

### Switcher

<kbd>Ctrl</kbd>+<kbd>Space</kbd> відкриває поле посеред сторінки, як швидкий перемикач Obsidian. Введіть текст, щоб шукати в закладках; наскільки неточним може бути пошук, визначає налаштування (сувора, звичайна або вільна). Якщо нічого не підходить, <kbd>Enter</kbd> шукає в мережі. <kbd>Tab</kbd> перемикає Google, DuckDuckGo, YouTube, Wikipedia, GitHub і ваші пошукові системи (будь-яка адреса з `%s`, наприклад інстанс SearXNG); типова пошукова система стоїть першою. Будь-яку з цих частин можна вимкнути.

Він запам'ятовує, що ви відкриваєте з нього: закладка, яку ви відкриваєте часто й нещодавно, піднімається в результатах. Вкладка «Статистика» в налаштуваннях показує, скільки разів відкривалася кожна сторінка і її вага, і скидає одну сторінку або всі.

| Клавіша | |
|---|---|
| <kbd>↓</kbd> <kbd>Ctrl</kbd>+<kbd>J</kbd> / <kbd>↑</kbd> <kbd>Ctrl</kbd>+<kbd>K</kbd> | рух |
| <kbd>Enter</kbd> | відкрити тут |
| <kbd>Ctrl</kbd>/<kbd>Alt</kbd>+<kbd>Enter</kbd> | відкрити в новій вкладці |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | наступна / попередня пошукова система |
| <kbd>Esc</kbd> | закрити |

Три команди, які вводять у switcher. Вони працюють і з кнопки на панелі інструментів, для сайту активної вкладки, а їхні слова можна змінити в Налаштування › Switcher:

| Команда | |
|---|---|
| `td` | темний режим увімкнути або вимкнути для поточного сайту |
| `ta` | аркуш стилів увімкнути або вимкнути для поточного сайту |
| `settings` | налаштування (`options` теж працює) |

### Нова вкладка

![Шість макетів нової вкладки: класичний, лише час, в один рядок, складений, кутовий і аналоговий.](docs/screens/layouts.png)

Дата й час, виведені з увагою, а під ними switcher. Шість макетів: класичний, лише час, в один рядок, складений (години над хвилинами), кутовий і мінімалістичний аналоговий годинник. Чотири типографічні стилі: Editorial (Instrument Serif і Inter), Swiss (Inter), Machine (IBM Plex Mono) і Book (EB Garamond), або ваші шрифти, встановлені на комп'ютері. Необов'язкове привітання з вашим ім'ям. Задайте список мов, і кожна нова вкладка називатиме дату однією з них, навмання.

Браузери тримають фокус в адресному рядку на новій вкладці, і жодне розширення не може його звідти забрати. Щоб одразу писати в switcher, вкладку замінюють новою на тому самому місці, яка починається з фокусом на сторінці; тоді адресний рядок показує адресу сторінки, а не порожній. У вкладці контейнера Firefox все лишається як є. Вимкніть *Зняти фокус з адресного рядка*, щоб зберегти поведінку браузера.

### Швидкість медіа

Кожне відео й аудіо відтворюється з швидкістю, яку ви задали, або з правилом сайту. <kbd>]</kbd> швидше, <kbd>[</kbd> повільніше, <kbd>\\</kbd> назад до 1×. Будь-яка швидкість від 0.91× до 1.09× є просто 1×. Якщо ви змінюєте швидкість власними елементами керування сайту, sobrio на цій сторінці не втручається. За бажанням відео й аудіо, що починають звучати самі, до того як ви торкнулися сторінки, призупиняються; без звуку вони відтворюються далі.

### Власні комбінації клавіш

Запишіть комбінацію клавіш у налаштуваннях і виберіть, що вона робить: відкрити switcher, шукати в пошуковій системі (або шукати виділений текст), перемкнути темний режим або CSS на сайті, темний режим скрізь, відкрити адресу тут або в новій вкладці, задати швидкість медіа, скопіювати посилання сторінки без параметрів відстеження (`utm_*`, `fbclid`, `gclid` та подібні) або відкрити налаштування. Їм потрібні <kbd>Ctrl</kbd>, <kbd>Alt</kbd> або <kbd>Meta</kbd>, або функціональна клавіша. Вони також працюють, коли фокус усередині вбудованого фрейма (Google Docs, плеєр відео), і завжди діють на сайт в адресному рядку.

## Налаштування

![Налаштування на вкладці Стиль: список перемикачів поруч із вкладками Стиль, Темний режим, Винятки, Switcher, Комбінації клавіш, Нова вкладка, Медіа та Статистика.](docs/screens/settings.png)

`settings` у switcher або налаштування розширення в `about:addons` / `chrome://extensions`. Одна вкладка на кожну частину: Стиль, Темний режим, Винятки, Switcher, Комбінації клавіш, Нова вкладка, Медіа та Статистика. Кожна зміна зберігається сама і одразу застосовується до відкритих вкладок.

Резервна копія внизу кожної вкладки зберігає все (налаштування, винятки, комбінації клавіш і пам'ять switcher) у файл і відновлює його в іншому браузері. Вітальний посібник, який відкривається один раз після встановлення, теж тут.

Локальні адреси (`localhost`, `127.0.0.1`, `192.168.x`, назви `.local` та решта вашого комп'ютера чи мережі) за замовчуванням не чіпаються, тож ваша робота показується як є; перемикач угорі вкладки Винятки це змінює.

Винятки задають сайти як `example.com` (лише цей сайт) або `*.example.com` (сайт і його піддомени), окремо для аркуша стилів і для темного режиму. Третій список зберігає власні анімації та переходи сайту, поки решта аркуша стилів застосовується; він починається з `chatgpt.com`, чий вигляд зсувається під час письма, якщо його анімації вирізати.

### Тема через `userContent.css`

У Firefox і LibreWolf sobrio читає ці змінні з `userContent.css` (з увімкненим `toolkit.legacyUserProfileCustomizations.stylesheets`) і використовує їх для темного режиму, switcher, налаштувань і нової вкладки. Вони мають пріоритет над кольорами в налаштуваннях. Правило `@-moz-document` залишає їх лише на сторінках розширень: жоден вебсайт їх не бачить.

```css
@-moz-document url-prefix("moz-extension://") {
  :root {
    --sobrio-background: #07090f;   /* dark mode, switcher and new tab background */
    --sobrio-text: #edf1ff;
    --sobrio-text-muted: #7c86a0;
    --sobrio-selection: #171d2b;    /* the selected row, and selected text */
    --sobrio-border: #4a5470;
    --sobrio-accent: #f5a9cf;       /* the selection bar and the matched letters */
    --sobrio-corners: square;       /* square or round: overrides the corners switch */
    --sobrio-font: "SF Pro Text";   /* optional: a font installed on this machine */
  }
}
```

Браузер читає `userContent.css` під час запуску, тож зміни з'являються після перезапуску.

## Встановлення

- **Chrome:** `chrome://extensions`, увімкніть *Режим розробника*, *Завантажити розпаковане* і виберіть цю папку.
- **LibreWolf:** встановіть `xpinstall.signatures.required` на `false` в `about:config`, запустіть `scripts/pack.sh` і відкрийте `dist/sobrio-<version>.xpi` з `about:addons` (*Встановити розширення з файлу*). Для швидкої спроби `about:debugging` › *Завантажити тимчасове розширення* працює без цього параметра.
- **Firefox:** релізні збірки встановлюють лише підписані розширення. Завантажте zip на [addons.mozilla.org](https://addons.mozilla.org/developers/) як *unlisted*, щоб отримати підпис для себе.

Firefox запитає один раз, чи зберегти нову вкладку, яку встановило розширення; збережіть її. Комбінацію клавіш можна змінити в `about:addons` › *Керувати комбінаціями клавіш розширень* або `chrome://extensions/shortcuts`.

На сторінках, де розширення не працюють (сторінки `about:` і `chrome://`, магазини розширень, PDF), комбінація клавіш замість цього відкриває switcher з кнопки на панелі інструментів. Кнопка на панелі інструментів завжди відкриває його теж. У Firefox кілька сторінок розпізнаються надто пізно (PDF без `.pdf` в адресі, сторінки помилок): там комбінація нічого не робить, а кнопка на панелі інструментів працює.

**Порада:** налаштуйте браузер або систему на темний вигляд. Сайти з власною темною темою (GitHub, YouTube та багато інших) тоді перемикаються на неї, а sobrio їх не чіпає.

## Розробка

Без етапу збирання і без залежностей npm.

```sh
node --test                                   # unit tests
python3 -I tools/marionette.py . <url>...     # headless LibreWolf/Firefox with sobrio loaded
python3 -I tools/cdp.py . <url>...            # headless Chromium with sobrio loaded
python3 -I tools/vendor-darkreader.py 4.9.133 # update the bundled Dark Reader
python3 -I tools/vendor-fonts.py              # update the bundled fonts
python3 -I tools/make-icons.py                # redraw the icons from the isotype's grid
scripts/pack.sh                               # dist/sobrio-<version>.zip and .xpi
```

Щоб випустити версію, підніміть номер у `manifest.json`, зробіть коміт і надішліть тег `v<version>`. Робочий процес випуску тестує, пакує й публікує реліз на GitHub із zip і xpi, а також надсилає zip на addons.mozilla.org, коли змінна репозиторію `AMO_PUBLISH` дорівнює `true` (із секретами `AMO_JWT_ISSUER` і `AMO_JWT_SECRET`).

Брендбук (ізотип, два кольори, шрифти й іконки) є в [docs/brand](docs/brand/README.md).
