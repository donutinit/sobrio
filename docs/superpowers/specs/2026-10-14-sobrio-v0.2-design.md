# sobrio v0.2: diseño

Fecha: 2026-10-14. Estado: aprobado por Diego en conversación ("autorizo todo"); las decisiones
de detalle las tomó el implementador y están justificadas aquí.

Parte de v0.1 (`2026-10-14-sobrio-design.md`); todo lo de ahí sigue vigente salvo lo que este
documento cambia.

## Intención

Diego quiere tres cosas encima de v0.1, en este orden:

- **A. Ajustes:** una página aparte para personalizar lo que hoy está fijo: el CSS como
  interruptores, el modo oscuro, las piezas del switcher y las excepciones por sitio con
  comodines. Además, que sobrio tome los colores de su tema (`~/dot/bin/theme`).
- **B. Nueva pestaña:** que sobrio sea la página de nueva pestaña y reemplace a Tabliss, con un
  enfoque mínimo: fecha y hora con jerarquía y elegancia, en cualquier idioma, con fuentes
  curadas, y el switcher centrado (hoy en una pestaña nueva el switcher sale en el popup de la
  esquina, y no le gusta).
- **C. Velocidad:** lo esencial de Global Speed, ajustable desde la página de ajustes.

**Éxito:** Diego desinstala Tabliss y Global Speed, cambia los ajustes sin tocar código y, con
`theme set`, sobrio toma los colores de su tema al reiniciar LibreWolf.

**Fuera de alcance:** CSS libre, horarios, arreglos por sitio de Dark Reader, fondos de imagen,
widgets de Tabliss más allá de fecha y hora, filtros de video, volumen extra, cambio de tono,
cuadro por cuadro, atajos personalizables de velocidad y sincronización entre dispositivos.

## A. Ajustes

### Modelo

`storage.local` guarda, además de `darkOff` y `cssOff`:

- `settings`: los ajustes. Lo que falta toma su valor por defecto; los números se acotan.
- `theme`: lo que llega del gancho de `userContent.css`, o `null`.

```js
DEFAULTS = {
  css: { corners: true, shadows: true, blur: true, animations: true, youtubePlayer: true,
         smoothScroll: true, thinScrollbars: true, fixedBackgrounds: true },
  dark: { enabled: true, detect: true, brightness: 100, contrast: 100, sepia: 0, grayscale: 0,
          background: '#000000', text: '#e8e6e3', selection: '' },   // '' = automático
  switcher: { bookmarks: true, autoSearch: true, commands: true, hints: true,
              engines: { duckduckgo: true, google: true, youtube: true, wikipedia: true, github: true } },
  newtab: { style: 'editorial', locales: [], clock: 'auto', date: true, time: true, switcher: true },
  speed: { enabled: true, speed: 1, step: 0.1, shortcuts: true, rules: [] },  // rules: [{pattern, speed}]
}
```

Rangos: brillo y contraste 50 a 150; sepia y escala de grises 0 a 100; velocidad 0.25 a 4;
paso 0.05, 0.1 o 0.25. Un valor fuera de rango o del tipo equivocado vuelve a su default. Los
colores deben ser `#rrggbb`.

v0.1 no guardaba `settings`, así que no hay migración: las listas `darkOff` y `cssOff` ya son
patrones válidos.

### Patrones de sitio

- `example.com` coincide solo con `example.com`.
- `*.example.com` coincide con `example.com` y con cualquier subdominio.
- Lo que se escribe en la página de ajustes se normaliza: minúsculas, sin esquema, sin ruta, sin
  puerto y sin punto final (`https://Docs.Example.com/x` → `docs.example.com`). Una entrada que
  no es un dominio (con espacios, vacía, `*` solo, `*.` sin dominio) se rechaza.
- `td`/`ta` para **apagar** agregan el `hostname` exacto. Para **prender** quitan todos los
  patrones que coinciden con el sitio; si alguno es un comodín, la fila lo dice:
  `Prender modo oscuro en a.example.com (quita *.example.com)`.

### Estilo: el CSS como interruptores

`style.js` arma el CSS a partir de `settings.css`; cada interruptor es una parte del CSS de v0.1
y todos empiezan prendidos, así que actualizar no cambia nada:

| Interruptor | Regla |
|---|---|
| `corners` | `*, *::before, *::after { border-radius: 0 !important }` |
| `shadows` | `box-shadow: none !important; text-shadow: none !important` |
| `blur` | `backdrop-filter: none !important; -webkit-backdrop-filter: none !important` |
| `animations` | `animation-duration: .01ms; animation-iteration-count: 1; transition-duration: .01ms; transition-delay: 0s` (todos `!important`) |
| `youtubePlayer` | con `animations`, la regla excluye `#movie_player` y su contenido, como en v0.1 |
| `smoothScroll` | `html { scroll-behavior: auto !important }` |
| `thinScrollbars` | `* { scrollbar-width: thin !important }` |
| `fixedBackgrounds` | `background-attachment: scroll !important` |

Si el gancho del tema trae `--sobrio-corners`, manda sobre `corners`: `square` lo prende y
`round` lo apaga. Con todo apagado el CSS queda vacío. `custom-css.js` desaparece.

### Modo oscuro

- `enabled` en falso: Dark Reader no se activa en ningún sitio.
- `detect` en falso: no corre el detector y Dark Reader queda encima también de los sitios oscuros.
- El tema de Dark Reader: `{brightness, contrast, sepia, grayscale, darkSchemeBackgroundColor,
  darkSchemeTextColor, selectionColor}`. Los colores salen del gancho del tema si existe y, si
  no, de los ajustes; `selection` vacío es `auto`.
- `td` con el modo oscuro apagado en general muestra `Prender modo oscuro en todos lados` y, con
  Enter, pone `enabled` en verdadero.
- Un cambio de ajustes se aplica en vivo: cada página escucha `storage.onChanged` y vuelve a
  llamar `DarkReader.enable` con el tema nuevo.

### Gancho del tema: `userContent.css`

sobrio lee variables CSS con nombre propio, de modo que cualquier usuario de Firefox o LibreWolf
puede teñirlo desde `userContent.css` (documentado en el README):

```css
@-moz-document url-prefix("moz-extension://") {
  :root {
    --sobrio-background: #07090f;   /* fondo del modo oscuro, el switcher y la nueva pestaña */
    --sobrio-text: #edf1ff;         /* texto */
    --sobrio-text-muted: #7c86a0;   /* texto secundario */
    --sobrio-selection: #171d2b;    /* fila seleccionada y selección de texto */
    --sobrio-border: #4a5470;       /* bordes */
    --sobrio-accent: #f5a9cf;       /* barra de selección y letras que coinciden */
    --sobrio-corners: square;       /* square o round */
    --sobrio-font: "Acumin Pro";    /* opcional: fuente local para la nueva pestaña y el switcher */
  }
}
```

- El `@-moz-document` limita las variables a páginas de extensiones: los sitios web no las ven.
  Verificado con un spike en LibreWolf 157: el popup y la página de background de sobrio las
  leen; example.com no.
- El background las lee al arrancar (`getComputedStyle` de su propio documento; en Chrome no hay
  documento ni `userContent.css` y no pasa nada) y guarda `theme` en `storage.local`. La página
  de ajustes también las lee al abrirse y actualiza `theme`.
- Prioridad: el gancho gana sobre los colores y las esquinas de los ajustes; la página de
  ajustes muestra "del tema (userContent.css)" en lugar de esos controles.
- LibreWolf lee `userContent.css` solo al arrancar: un `theme set` se ve al reiniciar el
  navegador.
- Colores que no son `#rrggbb` o `rgb()` se ignoran, uno por uno. `--sobrio-corners` solo acepta
  `square` o `round`; `--sobrio-font` se pasa tal cual a `font-family`.
- En dot, la plantilla `theme/templates/librewolf/userContent.css` agrega ese bloque con
  `bg0`, `fg0`, `fg2`, `bg2`, `border`, `accent`, la forma elegida con `theme square` y la
  fuente "texto" de `fonts.json`. Es un cambio en el repo de dot, con su propio checklist.

### Switcher

- Piezas: `bookmarks`, cada motor por separado, `autoSearch` (saltar solo al primer motor si no
  hay bookmarks), `commands` (`td`, `ta` y `ajustes`) y `hints` (la línea de atajos).
- El ciclo de Tab recorre solo lo prendido, en el orden fijo de v0.1. Sin bookmarks, el
  switcher abre en el primer motor prendido. La página de ajustes no deja apagar la última
  pieza que queda (bookmarks o un motor).
- Comando nuevo: `ajustes`, `settings` u `options` (exactos) abre la página de ajustes en una
  pestaña nueva. Funciona también en el popup.
- Colores: del gancho del tema si existe (`background`, `border`, `selection` para la fila,
  `accent` para la barra y las letras que coinciden, `text`, `text-muted`); si no, los de v0.1.
  Fuente: `--sobrio-font` si existe; si no, la del sistema.

### Página de ajustes

- `options.html` abierta en pestaña (`options_ui.open_in_tab`), y desde el switcher con
  `ajustes`.
- Misma estética que el switcher: fondo del tema o negro, columna de 640 px, bordes de 1 px,
  sin esquinas ni sombras, encabezados chicos en versalitas con interletraje.
- Secciones: Estilo, Modo oscuro, Excepciones (dos listas: CSS y modo oscuro, con campo para
  agregar y botón para quitar), Switcher, Nueva pestaña, Velocidad.
- Cada cambio se guarda solo (los deslizadores, 200 ms después de soltar) y se aplica en vivo
  en todas las pestañas. No hay botón de guardar.
- Textos en `_locales/en` y `_locales/es`.

## B. Nueva pestaña

### Página

- `chrome_url_overrides.newtab: "newtab.html"`. Firefox avisa una vez que una extensión cambió la
  nueva pestaña; el README lo menciona.
- Composición: fondo del tema o negro; centrado horizontal, el bloque a 38% de la altura. Arriba
  la fecha (chica, color secundario), abajo la hora (grande) y, 56 px debajo, el switcher sin
  fondo atenuado, de 560 px. Con el input vacío no hay lista ni línea de atajos: la página queda
  limpia hasta que escribes.
- Fecha y hora con `Intl.DateTimeFormat`: la fecha `{weekday: 'long', day: 'numeric', month:
  'long', year: 'numeric'}`, que da la forma correcta en cada idioma (en español "miércoles, 9
  de octubre de 2026"), y la hora `{hour: 'numeric', minute: '2-digit'}` con el idioma del
  navegador; el periodo del día (AM, p.m.) va aparte, chico y en color secundario. `clock`:
  `auto`, `24` o `12`. La hora se actualiza al cambiar el minuto.
- **Idiomas de la fecha (pedido de Diego a media implementación):** `locales` es una lista que
  él arma (francés, alemán, español, italiano, inglés…); cada pestaña nueva elige uno al azar
  y dice la fecha en ese idioma. Lista vacía: el idioma del navegador. Hasta 30, sin repetir.
- Ajustes: estilo tipográfico, la lista de idiomas (46 para elegir, cada uno escrito en su
  propio idioma con `Intl.DisplayNames`), formato de hora, mostrar fecha, mostrar hora y mostrar
  switcher.

### Tipografía

Cuatro estilos, cada uno una decisión cerrada de tamaño, peso e interletraje, con fuentes OFL de
Fontsource empacadas en `fonts/` (latín y latín extendido, unos 380 KB). Para escrituras fuera
del latín cae a la fuente del sistema.

| Estilo | Hora | Fecha | Por qué |
|---|---|---|---|
| Editorial (default) | Instrument Serif 400, enorme, `-0.02em` | Inter 400, 15 px, color secundario | Contraste de serif display contra sans neutra: jerarquía de revista. |
| Suizo | Inter 200, `-0.05em` | Inter 500, 12 px, mayúsculas, `0.14em` | Una sola familia; la jerarquía sale del peso y la escala. |
| Máquina | IBM Plex Mono 300 | IBM Plex Mono 400, 13 px | Coherente con su terminal y su nvim. |
| Libro | EB Garamond 400, números elzevirianos | EB Garamond 400, 19 px, versalitas | Tipografía de libro clásico. |
| Tema | `--sobrio-font` 300 | `--sobrio-font` 400 | Solo aparece si el gancho trae fuente: sus fuentes locales sin empacarlas. |

`tools/vendor-fonts.py` baja los paquetes del registro de npm, verifica su sha512 y copia los
`.woff2` y las licencias. Las licencias OFL van en `THIRD_PARTY_NOTICES.md` y en el paquete.

### El switcher en la nueva pestaña

- Es el mismo componente montado en línea.
- Los navegadores ponen el foco en la barra de direcciones al abrir una pestaña nueva y una
  extensión no puede quitárselo. Por eso: `Ctrl+Space` en la nueva pestaña de sobrio le manda un
  mensaje a esa página para enfocar el input (en lugar del popup), un clic en cualquier parte
  enfoca el input, y una tecla de texto con el foco en la página enfoca el input y escribe ahí.
- Al abrir una URL desde la nueva pestaña se navega en esa misma pestaña.

## C. Velocidad

- `speed.js`, content script en todos los frames desde `document_start`.
- Velocidad deseada de una página: la de la primera regla cuyo patrón coincide con el sitio; si
  ninguna, la global.
- Se aplica a cada `<video>` y `<audio>` del documento: a los que ya existen y a los que avisan
  con `loadedmetadata` o `play` (listeners en captura sobre `document`, que reciben eventos de
  medios aunque no burbujeen). Si la página cambia la velocidad por su cuenta (por ejemplo, el
  menú de YouTube), sobrio no pelea: esa velocidad queda para esa página hasta que navegue.
- Atajos, solo si el foco no está en un campo editable y sin modificadores: `]` sube un paso,
  `[` baja un paso y `\` vuelve a 1. Cambian la velocidad global (se guarda y se aplica en todas
  las pestañas); en un sitio con regla cambian solo esa página.
- Aviso: una cajita arriba a la izquierda con `1.2×` (y "solo esta página" si aplica) durante
  900 ms, en un shadow root cerrado, dentro del elemento en pantalla completa si lo hay.
- `enabled` en falso: sobrio no toca ningún medio ni escucha atajos.
- Ajustes: prendido, velocidad global (deslizador de 0.25 a 4 más botones 1, 1.25, 1.5, 1.75,
  2), paso, atajos y reglas por sitio (patrón y velocidad).
- No cubre medios dentro de shadow roots ni Web Audio.
