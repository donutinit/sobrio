# sobrio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extensión MV3 para Firefox, LibreWolf y Chrome que aplica el CSS de Diego, oscurece los sitios con el motor de Dark Reader y abre un switcher tipo Obsidian para bookmarks y motores de búsqueda.

**Architecture:** JS plano sin build. Content scripts en todas las páginas (`boot.js`, `custom-css.js`, `darkreader.js`, `detector.js`, `page.js`); el switcher se inyecta bajo demanda o corre en el popup; el background maneja atajo, bookmarks, aperturas y descargas con candados. La lógica pura vive en `match.js`, `detector.js`, `guard.js` y `boot.js` y se prueba con `node --test`.

**Tech Stack:** WebExtensions MV3, JS plano, `darkreader` 4.9.133 (bundle MIT copiado), `node --test` (Node 22 de lizeth), Python 3 stdlib para manejar navegadores en pruebas (Marionette para LibreWolf, CDP por pipe para Chromium).

**Spec:** `docs/superpowers/specs/2026-10-14-sobrio-design.md`

## Global Constraints

- Sin `package.json`, sin npm, sin build. Node solo para `node --test test/`.
- Firefox/LibreWolf `strict_min_version` `128.0`, `gecko.id` `sobrio@donutinit`; `minimum_chrome_version` `127`.
- Permisos exactos: `bookmarks`, `storage`, `scripting`; `host_permissions` `<all_urls>`.
- Atajo `Ctrl+Space` (`commands.open-switcher`).
- `darkreader.js` = `package/darkreader.js` de `darkreader-4.9.133.tgz`, byte por byte.
- Fondo oscuro `#000000`; el resto del tema en defaults del motor.
- `storage.local`: `{darkOff: string[], cssOff: string[]}` con `hostname` exactos.
- Descargas: solo `http:`/`https:`, `credentials: 'omit'`, solo `text/css` o `image/*`, máximo 5 MB (`5 * 1024 * 1024`).
- Motores en este orden: DuckDuckGo, Google, YouTube, Wikipedia, GitHub, con las URLs del spec.
- Textos de interfaz en `_locales/en` y `_locales/es`; README en inglés; `AGENTS.md` en español.
- Commits en inglés, minúsculas, cortos, sin trailers. Autor: config global de lizeth.
- Nada de rayas largas o cortas ni comillas curvas en textos en español.
- `AGENTS.md` canónico y `CLAUDE.md` hard link; después de editarlo, `liz-doc --fix`.

## Review Focus

- Bookmark con título vacío: se muestra y se busca por URL. Test en Task 2.
- Mayúsculas y acentos: `cancion` encuentra `Canción` y resalta las letras correctas. Test en Task 2.
- Consulta solo con espacios: se trata como vacía (recientes, sin salto automático). Test en Task 2.
- Primera instalación sin nada en `storage`: todo prendido, sin errores. Test en Task 3.
- Página sin `hostname` (about:blank, file://, data:): no hay comandos `td`/`ta`. Test en Task 2.

```text
fold(c) = c.normalize('NFD')[0].toLowerCase()   // 1:1 con el texto original
greedy de izquierda a derecha sobre el campo plegado; por cada letra encontrada:
  +1 base, +5 si la anterior también coincidió en la posición previa,
  +3 si está al inicio de palabra (índice 0 o precedida por no alfanumérico),
  -0.1 por cada caracter saltado desde la letra anterior.
palabra en título ×3, en carpeta ×2, en URL ×1; por palabra se toma el mejor campo.
score total = suma de palabras; si una palabra no coincide en ningún campo, el bookmark queda fuera.
```
