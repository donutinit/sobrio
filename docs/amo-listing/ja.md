# 日本語

## Summary

Web の見え方と、ブラウザの使い心地について独自の考えを持つ拡張機能です。Dark Reader のエンジンで黒くなるサイト、角丸や影、アニメーションのない表示、ブックマークと検索のためのキーボード操作の switcher、落ち着いた新しいタブを備えます。

## Description

sobrio は、Stylus、Dark Reader、Search Bookmarks History and Tabs、Tabliss、Global Speed の小さな一部分だけを取り出したもので、ほかは含みません。

すべてに一つのスタイルシート。角丸、影、テキストの影、ぼかしをなくします。アニメーションとトランジションは、YouTube のプレーヤーを除いてすべて削除します。スクロールバー、スムーズスクロールをなくし、背景はページと一緒にスクロールします。リンクには下線が引かれ、どのテキストも選択でき、強制的な大文字もありません。それぞれの項目はスイッチで、独自の CSS を書く欄もあります。

賢く黒く。Dark Reader の動的エンジンが、すべてのサイトを色ごとに黒くします。独自のダークテーマを持つサイトは、そのテーマを保ちます。

switcher。Ctrl+Space を押すと、Obsidian のクイックスイッチャーのように、ページの中央にボックスが開きます。入力するとブックマークを検索します。Tab で Google、DuckDuckGo、YouTube、Wikipedia、GitHub と、独自の検索エンジン（`%s` を含むアドレス、たとえば SearXNG のインスタンス）を切り替えられます。開いたものを記録し、結果の上位に上げます。td と ta で、現在のサイトのダークモードとスタイルシートを切り替えます。

新しいタブ。日付と時刻を整えて表示します。レイアウトは六種類、書体は四種類か独自のフォントから選べます。あいさつを任意で表示でき、日付は設定したリストの言語からランダムに選ばれます。下には switcher があります。

独自のショートカット、すべての動画と音声の再生速度を ] と [ で調整する機能、そして自動で音が鳴り出したメディアを一時停止する機能。

サイトごとの例外は、スタイルシート、ダークモード、アニメーションのそれぞれに設定できます。すべて自動で保存され、開いているタブにすぐ反映されます。データはブラウザの外に出ません。
