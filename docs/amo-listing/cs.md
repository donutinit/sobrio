# Čeština

## Summary

Rozšíření s názorem na to, jak má web vypadat a jak má prohlížeč působit: černé weby přes engine Dark Readeru, bez zaoblených rohů, stínů a animací, klávesový switcher pro záložky a hledání a klidná nová karta.

## Description

sobrio bere malou část z těchto rozšíření: Stylus, Dark Reader, Search Bookmarks History and Tabs, Tabliss a Global Speed, a nic dalšího.

Jeden styl, všude. Žádné zaoblené rohy, stíny, stíny textu ani rozostření. Animace a přechody jsou seříznuté na nulu, kromě přehrávače YouTube. Žádné posuvníky, žádné plynulé posouvání, pozadí se posouvají se stránkou, odkazy podtržené, jakýkoli text označitelný a žádná vynucená velká písmena. Každá položka je přepínač a je tu pole pro vlastní CSS.

Černě, chytře. Dynamický engine Dark Readeru zčerní každý web, barvu po barvě. Weby s vlastním tmavým motivem si ho ponechají.

Switcher. Ctrl+Space otevře box uprostřed stránky, jako rychlý přepínač v Obsidianu. Pište pro hledání v záložkách; Tab prochází Google, DuckDuckGo, YouTube, Wikipedia, GitHub a vašimi vlastními vyhledávači (libovolná adresa s %s, třeba instance SearXNG). Pamatuje si, co otevíráte, a řadí to výš. td a ta přepínají tmavý režim a styl na aktuálním webu.

Nová karta s datem a časem pečlivě sestavenými: šest rozložení, čtyři typografické styly nebo vlastní písma, volitelný pozdrav, datum v jazyce náhodně vybraném z vašeho seznamu a switcher pod ním.

Vlastní zkratky, rychlost médií pro každé video a zvuk pomocí ] a [, a pozastavení médií, která se spouštějí samy.

Výjimky pro každý web: pro styl, tmavý režim a animace. Vše se ukládá samo a hned se použije v otevřených kartách. Nic neopouští váš prohlížeč.

Zdrojový kód a dokumentace: https://github.com/donutinit/sobrio
