# 简体中文

## Summary

一个有主见的扩展：网页该是什么样子，浏览器该是什么感觉。通过 Dark Reader 引擎将网站变为黑色，没有圆角、阴影和动画，并提供用于书签和搜索的键盘 switcher，以及一个安静的新标签页。

## Description

sobrio 只取用 Stylus、Dark Reader、Search Bookmarks History and Tabs、Tabliss 和 Global Speed 中的一小部分，除此之外别无其他。

一个样式表，处处生效。没有圆角、阴影、文字阴影和模糊。动画和过渡效果全部剪除，YouTube 播放器除外。没有滚动条，没有平滑滚动，背景随页面滚动，链接加下划线，任何文字都可以选中，不强制大写。每一项都是一个开关，另外还有一个可以放入你自己 CSS 的输入框。

智能的黑色。Dark Reader 的动态引擎会逐色把每个网站变为黑色。已经拥有自己深色主题的网站会保留它。

一个 switcher。Ctrl+Space 会在页面中央打开一个框，类似 Obsidian 的快速切换器。输入即可搜索你的书签；Tab 会依次切换 Google、DuckDuckGo、YouTube、Wikipedia、GitHub 以及你自己的搜索引擎（任何包含 %s 的地址，比如 SearXNG 实例）。它会记住你打开过的内容并提高其排名。td 和 ta 可以开启或关闭当前网站的深色模式和样式表。

一个新标签页，日期和时间经过精心排版：六种布局、四种字体风格或你自己的字体，可选的问候语，从你的列表中随机选择语言显示日期，以及位于其下方的 switcher。

你自己的快捷键，每个视频和音频的媒体速度（用 ] 和 [ 调节），以及对自行开始发声的媒体的暂停功能。

每个网站的例外设置，适用于样式表、深色模式和动画。所有内容都会自动保存，并立即应用到已打开的标签页。内容不会离开你的浏览器。

源代码和文档：https://github.com/donutinit/sobrio
