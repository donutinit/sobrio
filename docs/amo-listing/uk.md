# Українська

## Summary

Розширення з власною думкою про те, як має виглядати веб і як має відчуватися браузер: чорні сайти через рушій Dark Reader, без заокруглених кутів, тіней і анімацій, клавіатурний switcher для закладок і пошуку та спокійна нова вкладка.

## Description

sobrio бере одну невелику частину від Stylus, Dark Reader, Search Bookmarks History and Tabs, Tabliss та Global Speed, і нічого більше.

Одна таблиця стилів скрізь. Без заокруглених кутів, тіней, тіней тексту й розмиття. Анімації та переходи вирізано повністю, крім відеоплеєра YouTube. Без смуг прокручування, без плавного прокручування, фони прокручуються разом зі сторінкою, посилання підкреслені, будь-який текст можна виділити, без примусових великих літер. Кожна деталь є перемикачем, і є поле для вашого власного CSS.

Чорне, але розумно. Динамічний рушій Dark Reader робить кожен сайт чорним, колір за кольором. Сайти з власною темною темою її зберігають.

Switcher. Ctrl+Space відкриває поле посеред сторінки, як швидкий перемикач Obsidian. Введіть текст, щоб шукати в закладках; Tab перемикає Google, DuckDuckGo, YouTube, Wikipedia, GitHub і ваші власні пошукові системи (будь-яка адреса з %s, наприклад інстанс SearXNG). Він запам'ятовує відкриті сторінки й піднімає їх у результатах. td і ta вмикають або вимикають темний режим і аркуш стилів на поточному сайті.

Нова вкладка з датою та часом, складеними з увагою: шість макетів, чотири типографічні стилі або ваші власні шрифти, необов'язкове привітання, дата однією з мов, вибраних навмання з вашого списку, і switcher під нею.

Власні комбінації клавіш, швидкість для кожного відео й аудіо клавішами ] і [, а також призупинення медіа, які починають звучати самі.

Винятки для кожного сайту: для аркуша стилів, для темного режиму й для анімацій. Усе зберігається само і одразу застосовується до відкритих вкладок. Ніщо не виходить з вашого браузера.
