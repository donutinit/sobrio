# 繁體中文

## Summary

一款有主見的擴充功能，談網頁應該長什麼樣子，以及瀏覽器應該給人什麼感覺：以 Dark Reader 引擎將網站變黑，沒有圓角、陰影或動畫，鍵盤切換器可搜尋書籤與搜尋引擎，還有一個安靜的新分頁。

## Description

sobrio 只取用 Stylus、Dark Reader、Search Bookmarks History and Tabs、Tabliss 與 Global Speed 的一小部分，別無其他。

一份樣式表，到處適用。沒有圓角、陰影、文字陰影或模糊。動畫與轉場效果全部截斷，YouTube 播放器除外。沒有捲軸、沒有平滑捲動，背景隨頁面捲動，連結加底線，任何文字都可以選取，也不強制大寫。每一項都是一個開關，另外還有一個方框供你輸入自己的 CSS。

聰明的黑色。Dark Reader 的動態引擎會把每個網站變成黑色，逐色轉換。本來就有自己深色主題的網站會保留它。

switcher。Ctrl+Space 會在頁面中央開啟一個方框，類似 Obsidian 的快速切換器。輸入文字即可搜尋你的書籤；按 Tab 可在 Google、DuckDuckGo、YouTube、Wikipedia、GitHub 與你自己的搜尋引擎（任何含有 %s 的網址，例如 SearXNG 執行個體）之間切換。它會記住你開啟過的項目，並讓它在結果中排得更前面。td 與 ta 會切換目前網站的深色模式與樣式表。

新分頁，日期與時間經過精心排版：六種版面、四種字體風格或你自己的字型、可選的問候語、從你的清單中隨機選出語言來顯示日期，以及位於其下方的 switcher。

你自己的快速鍵，每個影片與音訊都能用 ] 與 [ 調整速度，還能暫停自行發出聲音的媒體。

每個網站的例外，適用於樣式表、深色模式與動畫。所有內容都會自動儲存，並立即套用到已開啟的分頁。資料不會離開你的瀏覽器。
